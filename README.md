
# Conversor de Equivalências - Programa Educativo Lobinho

Projeto desenvolvido para auxiliar chefes de Alcateia na conversão do programa educativo antigo para o novo.

## Tecnologias

- HTML
- CSS
- JavaScript

## Como executar

Basta abrir o arquivo `index.html`.

## Como publicar no GitHub Pages

1. Crie um repositório no GitHub.
2. Faça upload de todos os arquivos.
3. Vá em:
   Settings → Pages
4. Em "Branch", selecione:
   main
5. Clique em Save.
6. Aguarde alguns minutos.
7. O site ficará disponível em:

https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/

## Estrutura

- index.html → interface
- style.css → visual
- script.js → processamento
- equivalencias.json → base de equivalências
